## `OPT-67-MEASUREMENT` evaluator

**Primary evidence:** construct map, decision brief, validity / evidence argument, precision and fairness review, technical report, residual-risk memo.

**Dimensions:** construct clarity; intended use; evidence sufficiency; technical quality; uncertainty; fairness / accessibility; consequences; reporting; improvement.

**Critical failures:** score-as-construct, validity claim without evidence, fairness claim without subgroup / context review, or university exemplar labeled consensus.

**Challenge set design:** reliable but invalid measure; subgroup disparity with missing context; high-stakes score-use proposal; university program document; agent evaluator with construct drift.

**Improvement loop:** diagnose unsupported claim → revise construct / evidence prompt → rerun technical audit → compare claim-to-evidence coverage and residual-risk disclosure.
